# 대화의 결 · Dialogue Texture

대화 속 반복되는 말투, 반응 순서, 관계의 흐름을 살펴보는 정적 HTML 보고서입니다.

최신 자료는 2026년 9월 10일 06:52까지이며 누계 72,170개, 핵심 4인 70,228개 메시지입니다. 9월 9일은 326개·182턴이며 10일은 아침 4개·3턴의 부분 기록입니다. 시작 화면은 9월 9일 일일보고서로 연결하며 10일 아침 기록은 지난 보고서 목록에서 볼 수 있습니다.

종합보고서와 네 개인 보고서의 `#mutual-understanding`에서 상호 이해와 대화 조율 분석을 볼 수 있습니다. 기준 공개·이해 확인·적용·갱신·마무리를 같은 틀로 살피며, 목적 표집한 10개 장면의 발화와 해석 범위를 구분합니다. 해당 10개 장면의 목적 표집 범위는 9월 5일까지이며, 후속 자료는 종합보고서 `#september-67-update`와 개인 보고서 `#september-67`에서 별도로 확인할 수 있습니다.

최신 후속 분석은 종합 `#september-910-update`와 개인 `#september-910`에 수록했습니다. 업무 평가와 호감의 구분, 위키 공유 실행 보고, 순차적으로 공개되는 선택 조건, 간식 나눔의 거절과 늦은 전달, 레몬즙 수령을 다룹니다.

## 보고서

- `index.html` — 보고서 시작 화면
- `관계_대화_분석_종합보고서.html` — 비밀번호 인증 후 복호화되는 장기 관계 분석 종합보고서
- `일일_대화_분석_2026-08-03.html` — 비밀번호 인증 후 복호화되는 2026년 8월 3일 일일보고서
- `일일_대화_분석_2026-08-04.html` — 비밀번호 인증 후 복호화되는 2026년 8월 4일 일일보고서
- `일일_대화_분석_2026-08-05.html` — 비밀번호 인증 후 복호화되는 2026년 8월 5일 일일보고서
- `일일_대화_분석_2026-08-06.html` — 비밀번호 인증 후 복호화되는 2026년 8월 6일 일일보고서
- `일일_대화_분석_2026-08-07.html` — 비밀번호 인증 후 복호화되는 2026년 8월 7일 일일보고서

종합보고서와 일일보고서 원문은 저장소에 평문으로 두지 않고 `assets/*.enc.json`에 암호화하여 보관합니다. 각 보고서의 인증 화면에서 비밀번호가 일치하면 브라우저 안에서만 복호화합니다.
